# ContentFactory 2.2.5 — исправление visual-repair и маршрутизации Wan

## Проблемы предыдущего запуска

- Gemma возвращала `video_prompt` для `image_animation`; из-за одного чужого поля отклонялось всё исправление сцены.
- Промежуточные сцены с camera-only движением оставались `ai_video`, поскольку прежний budget выбирал первую/последнюю сцену среди AI-сцен, а не первую/последнюю сцену таймлайна.
- Один пакетный visual-repair вызов путал поля нескольких сцен и маршрутов.
- Canonical identity details могли ошибочно восприниматься моделью как сюжетные anchors.

## Изменения

1. Wan budget теперь резервирует видеогенерацию только для реальных первой/последней сцен. Промежуточные `ai_video` с пригодными anchors переходят в `image_animation`.
2. `image_animation` всегда очищается от `video_prompt`; `motion_target` выбирается только из anchors, присутствующих в `visual_purpose` и `image_prompt`.
3. Если Wan-задание содержит только движение камеры и не содержит простого физического действия, оно переводится в `image_animation` с безопасным camera-only движением.
4. Visual-repair запускается отдельным запросом для каждой сцены.
5. Все смены маршрута и автоматические исправления попадают в `human_review`.
6. Тесты проверяют внутренние AI-сцены, ошибочный `video_prompt` у image_animation и безопасное переключение camera-only Wan-задания.
7. Проверка версии в `Test-Factory.ps1` больше не привязана к одной фиксированной версии; единственный источник — `VERSION.txt`.

## Дополнительная проверка версии

- Сообщение preflight в `Test-Factory.ps1` формируется из `VERSION.txt`; оно больше не содержит устаревший номер `2.2.4`.

## Что не менялось

- Строгий валидатор и JSON contract.
- Сценарий/озвучка и точное распределение scene narration.
- Claims и их привязка к script excerpt.
- Export contract и `schema_version=2.1`.
