# Установка ContentFactory v2.2.0 (патч)

Этот архив — **патч-оверлей**, а не полная установка. Он предназначен для существующей ContentFactory v2.1.x с исправлениями до v2.1.8.

1. Закрой процессы ContentFactory.
2. Сделай резервную копию всей текущей папки проекта.
3. Распакуй содержимое ZIP с сохранением относительных путей прямо в корень проекта, например `E:\TEMPO\vibecorutine\ContentFactory_v2.1`. Подтверди замену файлов.
4. Открой PowerShell 7 в корне проекта и выполни:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Test-Factory.ps1 -RunTests -CheckOllama
```

5. Если все проверки пройдены, создай новый пакет:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\factory.ps1 -Topic "Почему бедность обходится дороже богатства"
```

## Совместимость

- Версия приложения: `2.2.0` (единственный источник — `VERSION.txt`).
- `schema_version` намеренно остаётся `2.1`, чтобы старые пакеты продолжали читаться.
- Старые проекты не изменяются; новая генерация создаёт новую папку.
- В новых генерациях используется строгая проверка `visual_anchor_terms`, лимит Wan из локального профиля и речевое распределение длительностей.
- Автоматически созданный `reference_asset_path` — только планируемое местоположение PNG. Файл ещё не существует, пока ты не сгенерируешь и не утвердишь его в ComfyUI.
- Факты не проверяются в интернете. Утверждения без источников остаются в `human_review.txt`.

## Проверка отдельного старого пакета

По умолчанию `tools\Validate-Package.ps1` сохраняет режим совместимости. Для строгой проверки профиля v2.2 добавь `-RequireVisualAnchors -MaxAiVideoScenes 2`.

ContentFactory v2.2 создаёт производственные задания и экспорты, но пока не запускает TTS, ComfyUI, Wan или FFmpeg и не создаёт PNG/WAV/MP4.
