# ContentFactory 2.2.0 — patch notes

## Режиссура и визуальная согласованность
- Добавлена строгая цепочка `visual_purpose → visual_anchor_terms → image_prompt → video_prompt/motion_prompt`.
- Visual anchors должны быть дословно извлечены из английского visual_purpose и присутствовать в image_prompt; для ai_video все anchors повторяются в video_prompt. Поле motion_target обязательно: задано для image_animation и пусто для остальных маршрутов. Это лексический контроль, а не полноценная семантическая оценка сцены.
- Для image_animation `motion_target` — один из визуальных anchors; он должен присутствовать в исходном изображении и camera-only motion_prompt.
- Повторяющиеся персонажи получают единый путь identity reference PNG, reference prompt и прямую привязку файла в `visual_prompts.json.scenes[].continuity_reference_assets`.

## Тайминг и ресурсы
- Длительности сцен после синхронизации озвучки распределяются по фактическому количеству слов и границам предложений.
- По локальному профилю оставляется не более двух Wan-сцен; дополнительные промежуточные сцены переводятся в image_animation с записью в human_review.
- Проверяется темп речи в каждой сцене; строгий максимум по умолчанию — 2,8 слова/с.

## Содержательная аккуратность
- Сохранены проверки точных factual excerpts и запрет на необоснованное усиление утверждений об IQ.
- Ключевые пункты о профилактике, лечении и медицинских расходах должны быть содержательно отражены в сценарии; одно общее упоминание здоровья недостаточно.
- Общие заявления о цене единицы товара не считаются универсальным законом и требуют проверки конкретного рынка.

## Техническое
- Ollama продолжает работать с `think=false`; необязательное поле `message.thinking` не считается обязательным.
- Версия приложения читается из `VERSION.txt` и передаётся в `run_info.json`.
- Экспорт создаёт `assets/characters/` и содержит identity reference маршруты.
- `schema_version` остаётся `2.1` для обратной совместимости.
- Валидатор, экспорт, нормализатор, миграция и тесты предыдущих hotfix сохранены.

## Ограничения
Патч не генерирует медиа, не ищет источники и не собирает итоговый MP4. Identity reference PNG требует отдельной генерации и ручного утверждения. Таймлайн остаётся предварительным до синхронизации с реальным WAV.
