# Установка ContentFactory 2.2.6 — hotfix

Этот патч применяется поверх ContentFactory 2.2.5 (включая предыдущие hotfix). Проекты в `projects/` не перезаписываются.

1. Закрой запуски фабрики и сделай резервную копию папки проекта.
2. Распакуй архив непосредственно в корень `ContentFactory_v2.2`, сохранив относительные пути и разрешив замену файлов.
3. Выполни полный набор проверок:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Test-Factory.ps1 -RunTests -CheckOllama
```

4. При успешном завершении повтори генерацию производственного пакета.

Патч исправляет запись необязательных свойств в объектах, полученных через `ConvertFrom-Json`. Валидатор и контракт данных не ослабляются.
